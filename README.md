# 🚀 Smart Crypto Trading Bot (Beginner Version)

This project is a simple Python-based crypto trading bot designed for learning and demonstration purposes.  
It simulates how a trading bot fetches market prices and makes buy/sell decisions using a basic strategy.

---

## 📌 Features

- Fetches (mock) crypto price
- Applies a simple trading strategy
- Generates BUY or SELL signal
- Clean modular code structure
- Beginner-friendly project

---

## 🧠 How It Works

1. User enters a trading pair (e.g. BTCUSDT)
2. Bot fetches current price (dummy value for now)
3. Strategy checks price condition
4. Bot prints BUY or SELL signal
